### 🚀 Featured Projects

**[AgriSense AI](https://github.com/APEX-BUILDERS/AgriSense-AI)** — AI-powered smart farming platform for Indian agriculture. FastAPI backend on Google Cloud Run, Next.js 14 frontend, Supabase, GPT-3.5-turbo, and a MobileNetV2 model (trained on PlantVillage, 38 disease classes) for crop disease detection. Built with team **APEX BUILDERS**.

**[PrintFlow](https://github.com/Riteshkulkarni318/print-shop-platform)** — QR-based document upload platform for Indian print/xerox shops, solving the classic WhatsApp file-compression problem. FastAPI + Next.js 14 + Supabase, deployed on Render + Vercel.

**Mule Account Detection** — AI/ML system to flag suspicious mule accounts, built for the **PSB Cybersecurity, Fraud & AI Hackathon 2026** (Bank of India × IIT Hyderabad) with team **BYTEDetectives**. Uses XGBoost, SHAP, and a GenAI explanation layer on top of a pandas/scikit-learn pipeline.

**[Email Triage Env](https://github.com/Riteshkulkarni318/email-triage-env)** — Built for the Meta × Scaler × PyTorch OpenEnv Hackathon. FastAPI + Pydantic v2 + Docker, deployed on HuggingFace Spaces. Passed Phase 1 automated validation.
